## What's new

- Fixed the SNES mod installer so it requests `.snesmod` packages instead of
  the PSX-only `.psxmod` format.
- Restored the bundled **Widescreen (16:9)** option on the launcher’s
  **Mods** page. The experimental feature remains opt-in.
- Updated the pinned `recomp-ui` and `snesrecomp` revisions, including current
  launcher, renderer, runtime, and generated-code improvements.

## Notes

- Windows zip only. Extract the full archive, then run
  `MegaManXSNESRecomp.exe`.
- A verified Mega Man X (USA) ROM is required and is not included.
