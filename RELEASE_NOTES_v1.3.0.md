## What's new

- Added the new launcher mod loader and built-in mod catalog.
- Widescreen has moved from the general Settings page to the launcher’s
  **Mods** page. Enable the bundled **Mega Man X Widescreen** package there.
- Updated the Windows desktop build to SDL3.
- Included widescreen fixes for enemy spawn anchors and Highway background
  margins, plus the latest shared renderer, audio, crash-reporting, and
  launcher improvements.

## Notes

- Windows zip only. Extract the full archive, then run
  `MegaManXSNESRecomp.exe`.
- A verified Mega Man X (USA) ROM is required and is not included.
